### 💫 Về Tôi (About Me)

- 🔭 **Công việc & Hướng phát triển:** Kỹ sư phần mềm / Fullstack Developer tập trung vào xây dựng các ứng dụng web hiện đại, hệ thống quản lý dữ liệu hiệu năng cao và giải pháp tự động hóa/AI thực tế.
- 🌱 **Kỹ năng chuyên sâu:**
  - **Backend:** **PHP (Laravel, WordPress)**, **Python (FastAPI)**, Thiết kế RESTful API, tối ưu hóa truy vấn Database.
  - **Frontend:** **TypeScript / JavaScript**, **Next.js**, **React**, **TailwindCSS**, Blade Template.
  - **DevOps & QA:** **Docker**, CI/CD căn bản, Kiểm thử tự động (**PHPUnit**) và quy trình phát triển khắt khe (Clean Code, TDD/QA).
- 💬 **Đam mê kỹ thuật:** Tối ưu hóa truy vấn SQL, cấu trúc mã nguồn module hóa, an toàn bảo mật web (Web Security) và tính toán hiệu năng hệ thống.
- ⚡ **Phương châm làm việc:** *“Code sạch, kiến trúc rõ ràng, kiểm thử nghiêm ngặt trước khi xuất xưởng.”*
